# 双网盘上传助手

Windows 本地文件上传工具，支持百度网盘和阿里云盘。提供中文桌面窗口、独立扫码登录和 JSON 命令行，可上传文件或整个文件夹。

当前便携版本：**R06 · 2026-11-14**。本版修复百度引擎在缓存网络地址连接失败后无法回退到其他地址的问题。

## 下载使用

前往 [R06 Release](https://github.com/Wangmarco123/dual-cloud-uploader/releases/tag/v2026.11.14-r06)，下载便携版 ZIP。仓库为私有，下载时需要有访问权限的 GitHub 账号。

1. 完整解压到 Windows 10/11 x64 的可写目录。
2. 双击“检查运行环境.cmd”，再打开“启动上传助手.cmd”。
3. 分别在阿里授权窗口和百度独立窗口扫码登录。
4. 选择网盘、文件和目标目录，加入队列并开始上传。

便携包自带 Python 与两套上传引擎，无需另装 Python。扫码窗口需要 Microsoft Edge WebView2 Runtime 和 .NET Framework 4.7.2 或更新版本。

**GitHub 的 Code → Download ZIP 是源码，不能当作完整便携软件直接使用。** 日常使用请选择 Release 中名称包含“便携版”的附件。

## 功能与限制

- 上传单个文件、多个文件或整个文件夹，保留文件夹名称与子目录；空目录不单独上传。
- 阿里和百度分别授权，普通浏览器或网盘客户端登录状态不会自动共享给助手。
- 持久化本机队列，支持取消、有限重试和中断后的任务恢复。
- 默认快速核对：上传完成后读取同一路径的云端元数据，核对精确字节数，不回下载；阿里还比较可用的服务端 SHA1。
- 同名文件不自动覆盖。百度快速模式无法区分同大小不同内容，更新文件应使用新名称或新目录。
- 阿里续传依赖其底层引擎；百度失败时重传当前文件，不支持上传分片续传。
- 主窗口关闭按钮将其隐藏到托盘；从托盘“退出程序”真正退出。

默认目标目录为 `/我的作品`。阿里的备份盘和资源库可能有同名目录，上传前须核对当前工作盘。

## 命令行示例

以下命令适用于已解压的便携版根目录：

```powershell
$python = '.\runtime\python.exe'
$app = '.\cloud_uploader.py'
& $python $app status
& $python $app tasks
& $python $app add --provider baidu --remote '/我的作品/示例项目' '.\示例文件.txt'
& $python $app run
& $python $app tasks
```

记录 `add` 返回的任务 ID，再确认这些任务的 `status=complete`、`progress=100` 和实际 `verification`。`run` 会处理本机队列中所有 pending 任务，运行前先核对范围。

快速核对通过不能表述为“回下载 SHA256 内容校验通过”。额外完整内容核验只在明确需要时使用 `add --verification full`，它会整文件回下载并占用临时空间。

详细操作见 [命令行与账号说明](docs/CLI_GUIDE.md)。

## 本机数据与许可

默认账号及队列目录为 `%LOCALAPPDATA%\DualCloudUploader`；`DUALCLOUD_HOME` 可以指定独立数据目录。该目录不随源码或便携包分发。不要提交登录配置、Token、Cookie、浏览器资料、任务数据库或日志。
